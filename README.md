# Ферма: учёт животных

Приложение для телефона: овцы, коровы и лошади по биркам. Работает без интернета, все данные хранятся в самом телефоне. Сервер не нужен.

Что уже умеет (этап 1):

- **Реестр по биркам.** Карточка каждого животного: бирка, вид, пол, группа, возраст, мать, приметы, заметки, фото, статус. Поиск по номеру бирки. На главном экране видно, сколько голов каждого вида и группы.
- **Журнал событий.** Рождение сразу нескольких новорождённых (бирку можно присвоить позже), падёж с причиной, покупка, забой, ветеринарные отметки сразу на всё стадо. Статистика за окот, месяц и год.
- **Продажи.** Одно животное или сразу несколько, цена за голову или за килограмм. Доход сам попадает в финансы. Сводка: сколько продано, на какую сумму, средняя цена.
- **Пересчёт в поле.** Огромная кнопка +1, отмена и сброс. Сравнение с учётом и отметка «кого видел», чтобы понять, кто пропал.
- **Взросление.** Приложение само напоминает, что ягнят пора перевести в ярки или бараны. Группу меняете вы, одной кнопкой.
- **Резервная копия.** Сохранение всех данных в файл и восстановление из файла. Напоминание раз в неделю.
- **Тестовые данные.** Пример хозяйства, чтобы всё проверить. Удаляется одной кнопкой.

Следующий этап: сроки окота и отёла, корма, финансы с графиками.

## Как проверить

1. Откройте приложение (на компьютере или телефоне, см. ниже).
2. На главном экране нажмите **«Загрузить тестовые данные»**. Появится хозяйство на 86 голов с историей за два года.
3. Попробуйте:
   - найти бирку **102** в поиске на главном;
   - открыть «Пора перевести» в разделе «Скоро» и перевести ярку в овцематки;
   - нажать **«Пересчёт»**, выбрать овцематок, понажимать «+1», потом «Готово, сравнить» и «Отметить, кого видел»;
   - нажать **«Родились»** и записать двойню от овцематки **105**;
   - нажать **«Продажа»**, ввести бирки, указать цену;
   - посмотреть **Журнал → Статистика**, переключая «Окот», «Месяц», «Год».
4. Когда закончите: **Ещё → Тестовые данные → Удалить тестовые данные**. Ваши собственные записи, если вы их уже добавили, не пострадают.

## Как запустить на компьютере

Понадобится программа **Node.js** (бесплатно, https://nodejs.org, кнопка «LTS»). Установите её один раз.

Потом в папке проекта откройте терминал и выполните:

```bash
npm install
```

```bash
npm run dev
```

В терминале появится адрес вида `http://localhost:5173`. Откройте его в браузере. Если телефон подключён к тому же Wi-Fi, на нём можно открыть второй адрес из терминала (`Network: http://192.168.…:5173`).

Чтобы собрать готовый сайт в папку `dist`:

```bash
npm run build
```

## Как бесплатно выложить в интернет (GitHub Pages)

Сайт публикуется сам при каждом изменении ветки `main`. Настроить нужно один раз:

1. На GitHub откройте репозиторий → **Settings** → **Pages**.
2. В пункте **Source** выберите **GitHub Actions**.
3. Перенесите изменения в ветку `main` (например, примите pull request).
4. Откройте вкладку **Actions** и дождитесь зелёной галочки у «Публикация на GitHub Pages» (1–2 минуты).
5. Адрес сайта будет такой: **https://andrey82366373-blip.github.io/farm/**

Другой бесплатный способ, **Netlify**: зайдите на https://app.netlify.com/drop и перетащите туда папку `dist` (после `npm run build`). Netlify сразу даст ссылку.

## Как поставить на телефон папе (Android)

1. Откройте ссылку на сайт в **Chrome**.
2. Нажмите **⋮** (три точки справа вверху) → **«Установить приложение»** или **«Добавить на главный экран»**. Ещё можно зайти в раздел **«Ещё»** в самом приложении и нажать **«Установить приложение»**.
3. На экране телефона появится значок «Ферма» с жёлтой биркой. Дальше приложение открывается как обычное и работает без интернета.

Когда сайт обновляется, приложение обновится само при следующем запуске с интернетом. Данные при этом сохраняются.

## Чтобы ничего не потерялось

- Все записи хранятся **только в этом телефоне**. Раз в неделю приложение напомнит сделать копию: **Ещё → Резервная копия → Отправить копию**. Удобнее всего отправить файл себе в Телеграм, Ватсап или на почту.
- **Не очищайте данные Chrome** и данные сайта в настройках телефона: вместе с ними сотрутся записи.
- **Новый телефон:** установите приложение, откройте **Ещё → Резервная копия → Выбрать файл копии** и выберите последний файл `ferma-kopiya-….json`.

## Для того, кто будет менять код

Стек: React + Vite, данные в IndexedDB через Dexie, установка и работа без сети через vite-plugin-pwa.

| Где | Что |
| --- | --- |
| `src/lib/domain.js` | Виды, группы, возраст перевода молодняка, причины падежа. Названия групп и сроки меняются здесь. |
| `src/lib/db.js` | Хранение данных и все операции: рождение, падёж, продажа, бирки. |
| `src/lib/backup.js` | Резервная копия и восстановление. |
| `src/lib/demo.js` | Тестовые данные. |
| `src/screens/` | Экраны приложения. |
| `src/styles.css` | Весь внешний вид: цвета, размеры, кнопки. |
